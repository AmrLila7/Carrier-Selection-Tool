Carrier HVAC Database Schema

Relational Data Map for Selection Tool (SQLite/Access)

Relational Structure

  • • Primary Key: model_id ensures unique identification of each HVAC unit.
  • • Foreign Keys: Link performance and electrical data to the specific model.

Performance Logic

  • • Granular Data:-ESP points, 3 speeds, and 4 ambient temps per model.
  • • Matching: The app finds the lowest TR that meets the input criteria.

Selection Output

  • • Full Specs: Combines Model, Performance, and Electrical tables for one result.
  • • Engineering Precision: Uses specific catalog values for professional submittals.
